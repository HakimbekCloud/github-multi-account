# Changelog

## 1.2.0
- Renamed to **GitHub Multi-Account**; new plugin icon.
- Privacy section in the plugin description.
- Verified with Plugin Verifier on IntelliJ IDEA 2025.1, 2026.1, PyCharm 2026.1 and WebStorm 2026.2.
- Logging in to a new GitHub account now also works on 2025.1.

## 1.1.0
- Interface languages: English (default), O'zbekcha, Русский.

## 1.0.1
- Integration with the IDE's GitHub accounts: import, log in, an "IDE" status column,
  and the project's default GitHub account is set on switch.

## 1.0.0
- First release: status bar switcher, local `user.name` / `user.email`,
  GitHub login in HTTPS remote URLs, SSH key per account.
